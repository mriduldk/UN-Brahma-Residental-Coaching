How to Apply

Application Steps

  1. Register — Create your candidate profile with a valid mobile number and email.
  2. Select Post(s) — Tick the checkbox against each post you are eligible for and apply together.
  3. Fill Details — Enter educational, personal, and BTAD residency details once; it is reused for every selected post.
  4. Upload Documents — Photograph, signature, certificates (PDF, max 200 KB each).
  5. Pay Fee — ₹150 per post (SC/ST/OBC/PwD exempted) via UPI / net banking.
  6. Submit & Print — Download the system-generated acknowledgement for each post applied.
